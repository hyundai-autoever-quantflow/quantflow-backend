# 자동매수 일일 한도

자동매수 설정에는 주문당 매수 예산과 일일 최대 매수 횟수가 필요하다. `dailyLossLimitKrw`를 생략하거나 `null`로 등록하고 해당 설정을 활성화하면, 계좌 전체 손익 조회 없이 예산과 횟수를 적용한다. 기존에 손실 한도를 설정한 계좌는 현재 활성 설정의 한도를 적용한다.

## 계좌 전체 일일 손익

`일일 손익 = 현재 순자산 − 거래일 00:00(KST) 순자산 − 이후 순외부유입액`

순외부유입액은 같은 계좌 및 같은 기간의 입출금과 타 계좌와의 자산 이동을 순액으로 반영한다. 매도와 매수 등 계좌 내부 거래는 외부 자금 이동에 포함하지 않는다. 검증된 계좌 전체 원화 값을 `DailyRiskSnapshotSource`로 공급한다. 동일하거나 이전 관측 시각의 데이터는 최신 값을 덮어쓰지 않는다.

손실 한도를 사용하는 계좌는 `daily_risk_states`에 관측된 손익과 적용 설정을 저장한다. 토스 공개 API의 보유주식 일간 손익은 현재 보유 종목을 집계한다. 거래내역 명세는 취소로 인해 거래 금액의 합이 실제 잔액 변화와 다를 수 있다고 설명한다. 계좌 전체 순자산과 외부 유입액을 검증할 수 있는 운영 데이터 연결이 필요하다. 데이터가 없거나 1분 이상 경과하면 주문을 보류한다. [토스증권 공식 OpenAPI 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)

## 일일 매수 횟수

일일 최대 횟수는 `SUBMIT` 이벤트가 기록된 자동매수 주문을 주문 ID별로 집계한다. 전송을 시도한 주문은 이후 결과가 거절되거나 불명확하더라도 한 건으로 집계한다. 준비 상태의 주문은 전송을 시작할 때부터 집계한다.

주문 전송 상태, 이벤트와 손실 한도 적용 계좌의 집계값 갱신은 같은 DB 트랜잭션에서 반영한다.

## 자동매수 스케줄러

자동매수 스케줄러는 기본값이 꺼져 있으며 `AUTO_BUY_SCHEDULE_ENABLED=true`로 켤 수 있다. 손실 한도를 활성화한 계좌에는 검증된 손익 공급원이 필요하다. 기본 실행 주기는 한국 시간 08:00~16:59에 매분이며, 실제 주문 실행은 오늘의 추천이 저장되고 증권사 달력의 정규장이 열린 동안 가능하다. 실행 주기는 `AUTO_BUY_CRON`으로 바꿀 수 있다.
